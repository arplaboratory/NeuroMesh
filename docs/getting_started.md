# Getting Started

## Requirements

- Ubuntu 22.04
- ROS 2 Humble
- Python 3.10+
- Colcon and ROS build tools

## Quick start

1. Build your workspace with `colcon`.
2. Source ROS 2 and workspace overlays.
3. Launch one of the `neuromesh_platform_r2` launch files.

## Notes

- This branch targets ROS 2 Humble.
- Navigation integrations are optional and should be connected through adapters/bridges.
